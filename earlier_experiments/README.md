# Earlier experiments (not part of the paper)

Material from an earlier version of this work, kept unchanged for reference: the BreaKHis 40X
classification experiment, the generic real-image pipeline and its HIG implementation
(`src/hig_real_predictive_pipeline.py`), their notebooks, scripts, data notes and results.
None of it is used in the JMIV paper, whose experiments are reproduced by `../code/` (see the
main README). The notebooks can be run with `python ../scripts/execute_notebook.py breakhis`
or `real`.
